# @aieo/cli

The `aieo` command — SEO/GEO checks for a site's build output, crawler
logs and search engines; the inside view for [aieo.ee](https://aieo.ee).

```sh
npx @aieo/cli check            # or: npm i -g @aieo/cli && aieo check
```

This package runs a prebuilt native binary from the matching
`@aieo/cli-<platform>-<arch>` package. Documentation:
https://github.com/web-casa/aieo-cli
